# 碰撞检测报告模板

> 用法：每轮检测复制一份，改名 `碰撞报告_YYYYMMDD_第N轮.md`，按实际结果填充。报告只写"看得懂、能照着改"的信息。

## 分级口径

- **A 级 / 必须改**：穿结构梁柱、穿防火墙未加防火阀、净高不满足规范或任务书、检修空间被完全占死。
- **B 级 / 应改**：可通过翻弯/平移解决、支吊架空间不足、保温层冲突。
- **C 级 / 可接受**：表皮接触、软碰撞（间隙在允许误差内）、已确认无需处理的重复项。

> 分级不是拍脑袋：A 级必须写出"违反了哪一条"（规范条文或项目自定规则编号）。

字段说明：

- **碰撞编号**：按专业对 + 序号编，如 `C-001`（暖通×建筑）、`M-001`（机电互撞），便于跨轮次追踪同一处。
- **构件 ID**：Navisworks 里能看到的 Element ID，必须在 Revit 里能"按 ID 选择"定位到。
- **状态**：待整改 / 已整改 / 复检通过 / 接受（C 级）/ 作废（重复项）。

## 典型问题与处理（示例段）

### 1. 风管穿梁（A 级）

- 现象：2F 走廊送风管 800×400 与 KL-3 梁底净距 −120 mm。
- 原因：梁高按结构方案取 700，风管标高沿用标准层。
- 处理：风管整体下翻 150 mm，末端支管相应调整；复核走廊净高 ≥ 2.4 m。
- 复检：第 2 轮同一编号碰撞消失，净高 2.42 m。

### 2. 桥架与水管交叉（B 级）

- 现象：1F 电气桥架 300×100 与给水 DN80 在同一标高交叉。
- 处理：桥架抬高 100（贴梁底），水管保持；桥架填充率不变。

## 截图要求

- 每处 A 级碰撞一张截图：三维视图（能看到两个构件）+ 平面/剖面（能看到轴网与标高）。
- 截图前关闭项目信息、单位名称、文件路径；用统一视角与配色。
- 复检对比图：同一视角的前后两张，标注轮次。
