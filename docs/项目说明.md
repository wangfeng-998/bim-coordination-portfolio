# 项目说明

> 状态：初稿。选定建筑后补全尺寸、层高与专业范围。

## 1. 为什么选这个建筑

选择标准（按优先级）：

1. **体量可控**：2–3 层、建筑面积 3000–5000 m²，一个人 2–3 个月能建完，不会烂尾。
2. **专业齐全**：必须有集中的机房（空调机房、水泵房、配电间）与吊顶空间——机电协调的冲突主要发生在这里。
3. **有净高要求**：走廊、门厅、地下车库一类空间，能做出"净高不足"的真实案例。
4. **资料公开**：参照公开的建筑设计资料、规范尺寸自建，不碰真实项目图纸。

待定方向：社区服务中心 / 小型图书馆 / 社区医院门诊楼。三层以内、带一个集中机房的最合适。

## 2. 建模范围与深度

### 建筑（LOD300）

| 构件 | 要求 |
| --- | --- |
| 墙体 | 建筑墙，区分内外墙、材质分层（砌块 + 保温 + 面层） |
| 楼板 | 结构楼板厚度按方案取，开洞（楼梯、管井、风井）必须开 |
| 门窗 | 按门窗表建族，尺寸与编号对应 |
| 楼梯 | 按层高与踏步要求建，梯段净高 ≥ 2.2 m |
| 房间 | 全部房间放置并命名，面积方案开启 |
| 轴网/标高 | 轴网双向，标高到屋面 |

### 机电（各专业分开建模，再链接整合）

| 专业 | 系统 | 关键参数 |
| --- | --- | --- |
| 暖通 | 送风、回风、排风、空调水管 | 风管尺寸、保温层、标高 |
| 给排水 | 给水、排水、消火栓、喷淋 | 管径、坡度、保温 |
| 电气 | 桥架、母线、配电箱 | 桥架宽高、填充率 |

机电建模深度到"能跑碰撞"即可：管线走向、标高、管径正确，阀门附件可简化。

## 3. 协调规则（本项目自定）

1. 风管顶距梁底 ≥ 100 mm；水管与桥架交叉时桥架在上。
2. 走廊净高 ≥ 2.4 m，机房净高 ≥ 2.6 m，车库 ≥ 2.2 m。
3. 喷淋主管避让风管，支管可翻弯；翻弯后仍需满足净高。
4. 穿防火墙、楼板的管道必须预留套管并标注防火封堵。

## 4. 文件与版本

- Revit 模型按专业分文件：`建筑.rvt`、`暖通.rvt`、`给排水.rvt`、`电气.rvt`，用链接整合到 `协调中心文件.rvt`。
- 每次跑碰撞前导出一份 NWC 快照，命名 `YYYYMMDD_轮次.nwc`，报告里记录轮次，保证可复现。
- 模型文件不入库；仓库只放截图、报告与说明。
